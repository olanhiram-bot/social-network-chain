Social Network Portfolio Roadmap

Objetivo
Construir una red social inspirada en Facebook con arquitectura moderna...

Stack
Frontend
• Next.js
• React
• TypeScript
• Tailwind CSS
• TanStack Query
• Zustand
• React Hook Form
• Zod
• Framer Motion

Backend
• NestJS
• Prisma
• PostgreSQL
• Redis
• Socket.IO
• BullMQ

DevOps
• Docker, Docker Compose, Nginx, GitHub Actions

Arquitectura
Monorepo con Turborepo: - apps/web - apps/api - packages/ui - packages/types - packages/config

Fases

Fase 1 -- Autenticación
Objetivos: - Registro, login, JWT, Refresh Token. - Recuperación de contraseña. - Verificación por correo. Entidades: - User, Session. Entregable: - Usuario autenticado y perfil editable.

Fase 2 -- Perfil
• Avatar y portada.
• Biografía.
• Configuración de privacidad.
• Seguidores/amigos.

Fase 3 -- Feed
• Crear publicaciones.
• Texto, imágenes y video.
• Infinite scroll.
• Optimistic updates. Modelo:
• Post, Media.

Fase 4 -- Interacciones
• Reacciones.
• Comentarios anidados.
• Compartir publicaciones.

Fase 5 -- Amigos
• Solicitudes.
• Aceptar/rechazar.
• Bloqueos.

Fase 6 -- Chat
